# 운영판 인수 검수표

## 프런트엔드
- [ ] 4개 서비스에서 상품/패키지 이름·정확한 가격·핵심 혜택 확인 후 직접 선택.
- [ ] 사진/상세 펼치기가 다른 페이지를 강제로 열지 않음.
- [ ] 요트 내 정박형 분리, 라이트/올인원 가격·시간 및 꽃다발 조건 일치.
- [ ] 출장 두 패키지 장식 동일, USB와 촬영 동의 조건 표시.
- [ ] 헬기 원본 99만원/원본+추억영상 109만원 구분.
- [ ] 미정 상품 가격은 ‘상담 후 안내’. 0원/다른 상품 금액으로 대체 금지.
- [ ] 1순위 필수, 2순위 선택, 정확한 시간, 동일 일자 다른 시간 가능.
- [ ] 뒤로가기/회전/큰 글씨/키보드/선택 변경 시 입력·선택 유지.
- [ ] 접수 실패 시 완료 화면 금지. 재시도 1건만 생성.
- [ ] 고객 문자 앱 이동 없이도 접수 완료. 실제 SMS 전송 여부를 추정하지 않음.

## 관리자
- [ ] 각 카테고리에서 네 번째 요트 및 임의 신규 상품/패키지 추가 가능.
- [ ] 가격/설명/사진/구성/순서/노출 변경과 게시 결과 일치.
- [ ] 잘못된 금액/파일/URL을 서버에서도 거절.
- [ ] 저장 전 이동 시 손실 방지. 변경 이력과 관리자 권한 기록.
- [ ] 삭제/가격 변경 후에도 과거 접수의 선택/가격 스냅샷 유지.
- [ ] 실제 상담은 권한 없는 사용자와 다른 운영자에게 유출되지 않음.

## 알림/통합
- [ ] SOLAPI 전역 OFF에서 예약된 발송/재시도도 차단.
- [ ] 전역 ON이어도 고객/관리자 개별 OFF이면 미발송.
- [ ] 재ON 시 과거 신청 소급 발송 없음.
- [ ] 권한 거부/토큰 만료/푸시 실패가 접수 DB 저장을 취소하지 않음.
- [ ] iOS/Android 실제 홈 화면 PWA, 잠금화면 및 알림 딥링크 검증.
- [ ] 기존 OPS 읽기/최종 중복검사/명시 승인/멱등 등록/타임아웃 복구 검증.
- [ ] 실제 발송/캘린더 기록/배포 적용은 승인된 테스트 환경과 수신자만 사용.

## 기기·레이아웃
- [ ] 폴드 접힘·펼침 양방향, 일반 안드로이드, 아이폰 Safari·문자 앱.
- [ ] 아이패드/안드로이드 태블릿 양방향, PC 창 너비 변경.
- [ ] 화면 밖 가로 넘침, 가격 잘림, 한글 한 글자 줄바꿈, 겹침 없음.
- [ ] 200% 텍스트 확대, VoiceOver/TalkBack/키보드 탐색.
- [ ] 하단 안전영역/주소창 변화/키보드/가로 짧은 높이에서 제출 가능.
- [ ] OS 권한 거부, 오프라인, 느린 네트워크, 새 버전 갱신에서 정확한 상태 표시.

체크박스는 운영판의 실제 검증 후 채운다. 현재 시제품에서 실행한 범위는 tests/TEST_REPORT.md이며 이 표의 모든 항목 완료를 의미하지 않는다.
