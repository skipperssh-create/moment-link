# MOMENT LINK v2 — 실행형 프런트엔드 + Codex 개발 이관

**이 ZIP은 지시서만이 아닙니다.** 실제 HTML/CSS/JavaScript 앱, 상품 초기 데이터, 디자인 기준, 테스트와 개발 지시서를 포함합니다.

동시에 **운영 완성본도 아닙니다.** 로그인, 실제 접수 DB, 문자/푸시 서버, 기존 OPS 연동은 아직 없습니다. 인증 없는 관리자 데모를 운영 주소에 공개하거나 실제 고객에게 사용시키지 마세요.

## 바로 실행

압축을 풀고 `moment-link` 폴더에서 실행합니다.

macOS/Linux:
```bash
python3 -m http.server 4173 --bind 127.0.0.1
```
Windows:
```powershell
py -m http.server 4173 --bind 127.0.0.1
```
브라우저에서 `http://127.0.0.1:4173`을 엽니다. 운영 서버나 외부 계정에 연결하지 않습니다. 인터넷 없는 환경에서도 기본 UI를 볼 수 있도록 별도 단일 파일 `MOMENT_LINK_v2_preview.html`도 제공했습니다. 단일 파일은 PWA 설치 테스트용이 아닙니다.

## 실제 구현된 것
- 서비스 4종 선택, 요트 내 출항형/정박형 분리.
- 한 페이지에서 설명/가격/패키지 비교, 상세 펼치기, 직접 선택, 상담 후 추천.
- 1순위 필수/2순위 선택, 시간대 또는 정확한 시간, 중복·과거 날짜 검증.
- 고객 성함/연락처/조건부 장소/요청사항, 데모 동의, 완료와 SMS 작성 화면.
- 고객 문자 내용 생성, 선택적 문자 앱 열기와 복사. **자동 발송 아님.**
- 관리자 상품/패키지 추가·편집·삭제·노출·순서 변경, 사진 URL/소형 이미지 업로드.
- 모든 분야에 같은 관리자 CRUD 적용. 요트 3종 고정 제한 없음.
- 세션 내 상담 접수함, SOLAPI 전체/개별 스위치와 별도 푸시 설정 UI.
- 연락처/장소 기본정보 편집, OPS 연결 대상 안내.
- 반응형 레이아웃, 가격 한 줄, 모바일/가로 화면에 따른 재배치.

상품·설정은 **같은 브라우저의 localStorage**에 보관됩니다. 고객 입력은 **메모리에서만** 사용하며 새로고침 시 사라집니다. 상품 변경은 다른 기기와 동기화되지 않습니다. 저장 실패를 성공으로 표시하지 않습니다.

## 아직 구현·검증하지 않은 것
- 실제 관리자 로그인/권한과 감사 로그, 고객 운영 DB/API.
- 실제 SOLAPI 문자 발송/수신 연동, OS 푸시 전송.
- 고객 폰의 실제 SMS 앱과 PWA 설치/권한/백그라운드 알림.
- BOATN/KHT/설렘 예약 API 연결 및 실시간 가용 시간.
- 실제 상품 사진, 검증된 세부 지도/주차 동선.
- 휴일 요금 정책, 실제 계정의 GitHub/Vercel 배포와 도메인 연결.
- 실제 폴드/아이폰/태블릿에서의 키보드·회전·PWA 검수.

## v1 대비 중요한 수정
1. 애플풍 미니멀 디자인을 문서와 실제 CSS로 고정.
2. 가격을 줄이지 않고 카드 안에서 주중/주말을 정렬. 109만원도 한 줄.
3. 불필요한 시작/중복 확인 화면을 기본 경로에서 제거. 2순위는 선택적으로 펼침.
4. 고객이 정확한 희망 시간도 입력 가능.
5. 고객 신청 문자에 고객 관점 문구 사용, 2순위 미선택 생략.
6. 최종 휴일 규칙 확인 전 요일만으로 가격을 자동 확정하지 않음.
7. 미확정 요트 제공 품목과 검증되지 않은 상세 장소 주소를 판매 약속처럼 표시하지 않음.
8. 관리자 가격 입력 검증, 순서 변경, 숨긴/삭제한 선택 상품 처리, 메모리 접수 중복 방지.
9. 서비스워커는 이 앱의 지정 정적 파일만 캐시. API/개인정보 경로 캐시 금지.
10. 실제 실행한 테스트 결과와 미검증 범위를 분리해 첨부.

## 검증
`tests/TEST_REPORT.md`를 확인하세요. 20개 CSS 화면 크기와 고객/관리자 주요 흐름을 Chromium에서 실행했습니다. 제약된 실행 환경에서는 실제 CSS/JS를 렌더링하고 localStorage만 메모리 어댑터로 대체했습니다. 실제 저장소 유지, 네트워크, 모바일 앱 연동까지 검증한 것은 아닙니다.

```bash
node --check app.js
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python tests/test_preview.py --url http://127.0.0.1:4173
```
