# BOATN OPS 자동 예약 등록

## 사용 방법

1. 상담 상세 또는 관리자 직접 예약에서 확정한 날짜·시간·금액·장소를 입력합니다.
2. 출항 요트는 탑승 인원과 입금을 확인한 결제수단을 선택합니다.
3. 일정 협의·입금 확인 후 예약을 확정하면 OPS 등록 작업이 자동 시작됩니다.
4. 상세 화면의 BOATN OPS 등록 상태에서 완료 여부와 OPS 예약번호를 확인합니다. 실패·충돌이면 이유를 확인하고 재시도합니다.

## 등록 범위

- 클래식 → 레오파드 요트, 프리미엄 → 11호(메가), 시그니처 → 리파리. 출항형 라이트·올인원만 자동 연결합니다.
- 정박 상품은 실제 운항 요트를 지정해야 하므로 OPS에서 직접 등록합니다. 출장·트렁크·헬기는 OPS 요트 예약에 등록하지 않습니다.
- 기존 확정 건을 일괄 소급 등록하지 않습니다.
- OPS 등록 이후 일정·금액·인원 변경 및 취소는 OPS에서도 처리해야 합니다.
- 자동 문자 발송은 활성화하지 않습니다.

## 일관성·복구

모멘트링크의 예약 확정과 연동 작업 생성은 같은 DB 트랜잭션입니다. 작업은 즉시 실행하고, 미완료 작업은 관리자 목록 갱신과 일일 정리 작업에서 제한적으로 재시도합니다. 고정 외부 참조로 먼저 기존 등록을 조회하여 통신 시간 초과 후 재시도에도 예약을 중복 생성하지 않습니다.

OPS는 기존 최신 캘린더 조회·운항 가능 여부·탑승 한도·결제수단·동시 변경 검사를 통과한 예약만 기존 원자적 등록 경로로 저장합니다. 캘린더 입력·예약·입금·감사 기록은 함께 저장하며, 조회가 불확실하면 등록을 중단합니다. 모멘트링크의 확정 여부와 OPS 등록 성공 여부는 별도로 표시합니다.

## 운영 환경 변수

OPS: MOMENT_LINK_ENABLED, MOMENT_LINK_TOKEN_HASH(SHA-256).
모멘트링크: OPS_WRITES_ENABLED, OPS_BOATN_CONTRACT_VERIFIED, OPS_BOATN_BASE_URL, OPS_BOATN_TOKEN(암호화 비밀값).
연동 주소: https://boarding.boatn.co.kr/api/integrations/moment/v1/
연결 키는 저장소에 기록하지 않습니다. 중지 시 OPS_WRITES_ENABLED=false 또는 MOMENT_LINK_ENABLED=false로 설정합니다.

## 검증 · 2026-11-02

모멘트링크 68개 테스트, OPS 3,054개 테스트 및 TypeScript 검사 통과. 합성 데이터와 모의 OPS 어댑터로 관리자 직접 예약 → 확정 → OPS 등록 완료 UI 흐름을 확인했습니다. 8개 화면 크기에서 가로 넘침이 없고 완료 표시를 확인했습니다. 운영 실예약을 테스트 목적으로 생성하지 않았습니다.
