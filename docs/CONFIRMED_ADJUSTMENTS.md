# 확정 예약 옵션 취소·환불

상담 상세의 예약 확정 아래에서 취소 품목, 총액 차감액, 실제 환불액과 사유를 저장한다. 실제 환불 완료 체크가 필요하며 은행 송금이나 문자는 실행하지 않는다. 예: 총액/입금 398,000원에서 꽃다발 30,000원 제외·30,000원 환불 → 총액/순입금 368,000원, 잔금 0원, 확정 유지.

- 요청 UUID·예약 버전·직원 권한·금액 검증과 감사 이력. 응답 유실 시 같은 요청 결과를 재확인하고 OPS 쓰기는 최대 2회.
- 요트는 BOATN의 검증된 환불 영수증을 받은 후 로컬 금액을 확정한다. 원래 수납 영수증과 보딩패스는 보존하고 별도 환불 이력 및 꽃다발 준비 수량을 갱신한다.
- 기존에 연결된 출장·트렁크는 설렘 OPS 원래 예약의 총액·순수납·누적 환불을 갱신한다. Google 일정은 기존 이벤트 ID로 갱신하고 설렘은 별도 이벤트를 생성하지 않는다.
- 기존 OPS/캘린더 충돌은 변경하지 않는다. 과거 미연결 예약을 일괄 등록하지 않는다.
- 문자 초안과 캘린더 설명에 취소 사유·차감·환불 기록을 포함한다. 원본 상담 상품 스냅샷은 보존하고 취소 옵션은 현재 안내에서 제외한다.

검증: 합성 DB/API의 출장·트렁크 동기화, 동일 요청 재사용, 응답 유실, 기존 충돌 보존 및 요트 환불 원장 보존. 로컬 합성 브라우저 390×844, 768×1024, 844×390에서 저장/금액/문자 초안/가로 넘침 확인. 실제 고객 예약 변경·송금·문자 발송 0건. 실물 폰과 실제 고객 환불 연동은 실행하지 않았다.
