# 고객별 단계별 문자 안내

2026-11-01 사용자 요청에 따라 관리자 상담 접수함의 고객 번호에서 접근합니다. 기존 고객 화면과 상품 가격·사진은 변경하지 않습니다.

| 단계 | 내용 |
|---|---|
| 예약 접수·금액 안내 | 선택 상품·옵션, 협의 일정, 최종 금액, 우리은행 계좌, 입금 후 회신 안내. 요트·출장에는 사용자가 제공한 환불 비율을 정리합니다. |
| 결제 후 예약 확정 | 담당자의 입금 확인과 일정·장소 확정 후 예약 내용 및 상품별 준비사항을 안내합니다. |
| 하루 전 안내 | 확정 일정·장소와 현장 준비사항을 다시 안내합니다. 발송은 담당자가 직접 시작합니다. |
| 이벤트 후 안부 | 분야별 감사 인사, 만족도·불편사항 회신 안내를 제공합니다. |

요트 영상편지 준비는 접수 당시 패키지에 영상편지가 포함된 경우에만 안내하며 행사 7일 전 제출일을 계산합니다. 출장 라이트는 영상편지 옵션을 선택한 경우에만 제작 자료 안내를 넣습니다. 트렁크는 해운대 사무실 방문 / 부산 출장을 구분합니다. 헬기는 주간 운항·기상에 따른 최종 장소 확인과 편지 낭독 안내를 사용합니다. 확인되지 않은 상세 주소·트렁크/헬기 환불률은 만들지 않습니다.

## 사용 순서

1. 상담 접수함에서 고객 번호 · 문자 안내를 누릅니다.
2. 안내 단계를 선택합니다. 최초에는 협의한 시간과 최종 금액·장소를 입력합니다. 주중/주말 금액이 다르면 최종 금액을 직접 확정합니다.
3. 확정·하루 전 안내는 일정·장소와 입금 확인을 체크합니다. 날짜·시간·장소 변경 시 일정 확인이, 금액 변경 시 입금 확인이 해제됩니다.
4. 본문을 확인하고 필요하면 수정한 뒤 저장하고 문자 준비를 누릅니다. 일정 등의 항목을 변경하면 네 단계 문구가 다시 생성되므로 개별 문구 수정은 항목 확정 후 진행합니다.
5. 번호 · 문자 앱 열기를 눌러 휴대폰 문자 작성 화면으로 이동하고 전송을 직접 누릅니다. PC 또는 본문 입력 미지원 기기에서는 문구 복사를 이용합니다.
6. 실제 전송 후 휴대폰에서 발송 완료했어요를 눌러 담당자 확인을 남깁니다.

문자 앱 열기 요청은 전송 성공이나 수신 확인을 뜻하지 않습니다. 발송 확인도 담당자의 수동 기록입니다. 서버 SMS·OPS 작업은 생성하지 않으며 자동 발송 설정을 활성화하지 않습니다. 통신사 문자 요금은 사용 중인 요금제에 따릅니다.

## 데이터와 호환성

날짜·시간·금액·장소·확인 체크, 단계별 본문, 최근 40건의 단계·기록종류·담당자·시각·본문 해시를 해당 상담의 비공개 컬럼에 저장합니다. 기존 접수 상품/가격 스냅샷과 OPS 상태는 그대로입니다. 관리자 또는 배정된 상담원만 읽고 수정할 수 있고, 상담 만료·삭제 시 함께 삭제됩니다. 브라우저 저장소나 서비스 워커에 고객 데이터를 저장하지 않습니다.

Android 계열에는 `sms:number?body=...`, iOS 계열에는 `sms:number&body=...`를 준비합니다. URI의 본문은 UTF-8 퍼센트 인코딩합니다. [SMS URI 표준](https://datatracker.ietf.org/doc/html/rfc5724)은 body 필드를 정의하지만 [Apple의 URL Scheme 문서](https://developer.apple.com/library/archive/featuredarticles/iPhoneURLScheme_Reference/SMSLinks/SMSLinks.html)는 번호 연결만 보장하므로, 본문 지원은 기기에 따라 다를 수 있어 복사 대안을 함께 제공합니다. 실제 iOS/Android 문자 앱 호출·전송은 아직 실기기 검수하지 않았습니다.

## 검증

자동 테스트 총 41개 통과. 카테고리·패키지별 문구, 영상 옵션, 제출일 계산, 금액 확인, 문자 URI 인코딩, 미인증/미배정/CSRF 차단, 버전 충돌, 기록 재시도 중복 차단, 보유기한 삭제, 발송/OPS 작업 미생성 검증을 포함합니다. 초기 계정 이름 변경 후 재마이그레이션 시 초기 계정 미생성도 검증했습니다.

합성 데이터 브라우저에서 번호 선택, 4단계 전환, 일정·금액 자동 반영, 확인 전 확정 준비 차단, 저장 후 다시 열기, 복사 동작을 확인했습니다. 320/390/768/844 가로/1440 화면에서 가로 넘침 없이 표시됩니다. 실제 고객에게 문자를 보내지 않았습니다.
