# 중복 상담 연결

새 상담에서 전화번호를 입력하거나 붙여넣으면 기존 상담을 표시합니다. 같은 예약은 선택 후 **이 예약에 내용 추가**, 별도 예약은 **다른 날짜·별개 예약으로 새 상담 만들기**를 선택합니다.

이미 두 건을 만들었다면 확정·결제 기록이 없는 중복 상담 상세에서 **기존 상담에 연결**을 누르고 유지할 예약과 동일 예약 여부를 확인합니다. 예약·금액·고객 문자·외부 OPS 및 캘린더는 변경하지 않습니다. 원문 메모는 기존 예약 상세에서 출처와 함께 표시됩니다.

중복 상담은 취소 처리하지 않고 **연결된 상담**에 보관합니다. 일반 목록·접수 알림·상담 수 통계에서 제외합니다. 러브헌터 전화번호당 최초 수수료 금액·접수일을 유지하고 정산의 상담 상태는 유지한 예약을 따릅니다.

양쪽 담당 권한이 필요합니다. 확정·결제·취소·외부 연동 기록이 있는 원본이나 OPS 충돌 대상은 연결할 수 없습니다. 다른 번호, 변경된 버전, 연결된 상담을 다시 잇는 작업도 차단합니다. 원문 메모는 기존 개인정보 보유기한을 따릅니다.

검증: 클라우드 PGlite/API 검사 44개 통과. 브라우저에서 로그인 → 중복 연결 → 보관 원본 → 유지 예약 → 동일 번호 붙여넣기 → 추가 수수료 없음 확인. 320/390/549/740/844/768/1024/852/1153/1280 폭의 10개 화면 크기에서 팝업 잘림·가로 넘침 없음. 실제 접이식 기기의 회전 센서를 검증한 것은 아닙니다. 외부 발송 및 운영 데이터는 이 합성 검수에 사용하지 않습니다.
