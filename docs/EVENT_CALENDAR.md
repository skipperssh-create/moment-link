# 출장·트렁크 전용 캘린더

확정 예약은 기존 `모먼트링크 출장 이벤트` Google Calendar에 등록한다. 출장·트렁크는 제목으로 구분한다. 요트·헬기 캘린더는 접근하지 않는다.

`011_event_calendar.sql`은 별도 `event_calendar_jobs`와 트리거만 생성하며 기존 상담·예약·OPS 작업 행을 갱신하지 않는다. 예약 확정과 연동 작업 생성은 같은 트랜잭션이다. 확정 일정·금액 변경, 취소·복원 및 상담 상태 변경이 같은 이벤트를 갱신한다. 상담중으로 되돌린 뒤 저장한 미확정 일정은 재확정할 때 반영한다. 취소는 제목 표시와 일정 비점유로 처리하여 기록과 복원이 가능하다.

저장 직후 서버 후속 작업과 기존 2분 서버 호출에서 미완료 작업을 처리한다. 변경 버전별 최대 2회이며 충돌은 자동 재시도하지 않는다. 개인정보 없는 상태는 관리자 인증 후 `/api/admin/calendar-jobs`에서 조회한다. `EVENT_CALENDAR_ENABLED=true`일 때만 전송한다. 기존 요트 OPS 큐는 이 작업자가 실행하지 않는다.

Google 인증은 이미 설치된 BOATN Calendar Bridge의 단기 자격증명을 서버 내부에서 재사용한다. `/api/integrations/moment/v1/non-yacht-calendar`는 기존 연동 토큰으로 인증하고 지정 캘린더만 허용한다. OPS 예약·설정에는 쓰지 않는다. Google 토큰은 모먼트링크나 고객 브라우저로 전달하지 않는다. Calendar Bridge 연결이 해제되면 실패 기록을 남기고 자동 생성 성공으로 처리하지 않는다.

동일 접수번호의 기존 이벤트를 먼저 조회하고, 일치하는 1건만 연결한다. 기존 일정은 최초 연결 시 수정하지 않는다. 신규 이벤트 ID는 상담 UUID로 결정해 응답 유실에도 중복 생성되지 않는다. ETag와 마지막 확인 스냅샷으로 캘린더의 외부 수정을 보호한다. 수기 메모는 보존한다. 신규 이벤트의 종료 시각은 기존 캘린더와 같은 1시간 표시 구간이며 실제 진행시간을 의미하지 않는다고 설명에 명시한다. 기존 일정의 시간 길이는 변경하지 않는다. 참석자 초대·문자·메일은 보내지 않는다.

설렘 OPS는 아직 연결하지 않는다. 향후 설렘 OPS 어댑터와 별도 외부 예약 ID를 추가하고, 모먼트링크 상담 UUID를 공통 키로 사용한다. 캘린더 이벤트 ID와 OPS 예약 ID는 서로 대체하지 않는다. 기존 캘린더를 중복 생성하거나 요트 OPS 작업을 설렘 작업으로 전환하지 않는다.

되돌리기: `EVENT_CALENDAR_ENABLED=false` 후 이전 배포로 되돌린다. 기존 예약과 캘린더 이벤트는 그대로 보존한다. 연동 테이블은 삭제하지 않는다.
