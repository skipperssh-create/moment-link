# 상담 유입경로와 통합 운영 정산

## 사용 방법
- 새 상담에서 러브헌터 / 설렘 / 기타(수기입력)를 반드시 선택합니다. 기타는 경로명을 직접 입력합니다.
- 번호·이름·요청을 붙여넣거나 전화번호와 이름을 직접 입력합니다. 원문은 직원 전용 상담 메모이며 고객 문자·안내문에 포함하지 않습니다.
- 같은 번호의 상담이 있으면 담당 권한이 있는 기존 건을 선택해 연결하거나 별개 일정임을 확인하고 새 상담을 만듭니다. 연결만으로 기존 예약 상태·일정·금액·OPS를 수정하지 않습니다.
- 러브헌터 선택 시에만 최초 전화번호 1회 일반 50,000원 / 출장 40,000원을 기록합니다. 설렘·기타는 소개 수수료 0원입니다. 같은 번호의 재접수·상품 변경·예약 취소로 수수료를 추가하지 않습니다.

## 매출·비용·통계 (관리자 전용)
- 조회 월의 행사일에 해당하는 확정·완료 예약별 현재 예약매출, 입금 누계, 미수금, 감액·환불을 표시합니다.
- 예약 총액은 감액 반영 후 금액입니다. 반영된 환불을 다시 매출에서 차감하지 않습니다. 취소 예약은 매출에서 제외하고 남아 있는 입금 기록은 확인 대상으로 표시합니다.
- 입금·환불은 예약별 누계입니다. 은행 거래일별 현금출납장으로 표시하지 않습니다.
- 소개 수수료는 최초 접수월, 설렘 광고비는 관리자 입력 월별 총액, 추가 비용은 지정 귀속월에 집계합니다.
- 월별 광고비·누적 지급액·수수료 지급액, 추가 비용(재료·인건비·출장·대관·기타), 지급액, 증빙상 부가세, 거래처·증빙 메모를 기록합니다. 실제 이체는 실행하지 않습니다.
- 빈 금액은 미입력으로 유지합니다. 광고비가 없으면 0원을 명시합니다. 광고비나 예약금액이 미입력된 월은 관리손익을 확정 표시하지 않습니다.
- 유입경로·상품별 집계, 접수월 기준 현재 전환율, 행사월 매출 대비 당월 집객비 ROAS, 12개월 추이, 예약별·수수료별·환불별 상세, CSV를 제공합니다.
- 관리손익은 기록한 예약매출에서 소개비·광고비·추가 비용을 뺀 운영 참고값입니다. 행사월과 비용 귀속월 기준이 혼재하며, 미입력 원가·인건비·세금과 정식 회계 조정을 포함하지 않습니다. 회계상 순이익·부가세 신고액을 자동 산출하지 않습니다.
- 비용 수정은 버전 검사를 거칩니다. 제외 내역과 수정 전후 값·작성 계정을 이력에 남기며, 비용을 중복 청구하거나 자동 송금하지 않습니다.

## 데이터 보존과 안전
- 기존 상담·예약·OPS·캘린더 원본을 마이그레이션으로 변경하지 않습니다.
- 새 상담에는 유입경로를 명시합니다. 기존 러브헌터 출처는 기존 기록을 읽고, 그 외 미확인 과거 출처는 미분류로 남깁니다. 소급 수수료를 만들지 않습니다.
- 금융 집계용 테이블에는 이름·전화번호·상담 원문을 복사하지 않습니다. 삭제·보유기간 만료 후에도 금액·상태·분류별 집계 사실을 보존합니다. 고객명은 보유기간 내 상담을 조회할 때만 결합합니다.
- 기존 예약 수정·환불·일정 변경이 저장되면 DB 트리거가 집계용 사실을 함께 갱신합니다. 이 트리거는 OPS·캘린더·문자 작업을 생성하지 않습니다.
- 정산 API는 관리자 권한, 쓰기 API는 CSRF 검증이 필요합니다. 다른 담당자의 상담은 새 상담 중복 후보에서 이름·접수번호를 노출하지 않습니다.
- CSV는 수식 주입 문자를 이스케이프합니다.

## 검증 (2026-11-21)
- 전체 기존 검사 포함 296개 통과. 이후 미입력 금액·한국 시간 월 경계 검사를 추가하여 관련 검사 19개 통과.
- 클라우드의 격리된 합성 DB/실제 앱 UI로 세 경로 접수, 기존 상담 연결, 중복 수수료 방지, 광고비·추가 비용 저장, 집계 일치, CSV 다운로드를 검증했습니다.
- Chromium 화면 폭 360/390/884/1104/1440px에서 가로 넘침·금액 잘림을 확인했습니다. 실물 휴대전화 검증을 의미하지 않습니다.
- 운영 고객 예약·실제 문자·실제 송금·기존 OPS 충돌은 테스트에 사용하지 않았습니다.
