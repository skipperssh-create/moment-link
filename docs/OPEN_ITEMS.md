# 미확정 / 실제 연동 전 확인사항

아래 내용이 빠졌다고 사용자에게 모든 개발을 중단하고 다시 질문하지 않는다. 먼저 독립적으로 완료 가능한 기능을 만들고, 해당 보장 문구/운영 활성화만 보류한다.

1. **운영 저장소·환경**: GitHub 새 저장소 생성/자동배포 연결은 미완료. Vercel 미리보기 프로젝트와 주소는 deployment/에 실제 생성 기록이 있다. 사용자 소유 도메인 DNS는 아직 변경하지 않음. 기존 OPS 저장소를 임의 수정하거나 이름만으로 추정하지 않는다.
2. **주중·주말의 정확한 적용 범위**: 공휴일/공휴일 전날/특정 요일/시간대 정책 미확정. 요일만 보고 최종 단일 금액을 확정하지 않는다.
3. **요트 상세 구성**: 영상편지·촬영·와인·포토데코·폭죽 등 패키지별 구성과 라이트 꽃다발, 정박형 꽃다발 조건. 고객이 확정한 올인원 꽃다발 조건은 그대로 유지.
4. **실제 사진**: 운영 선박·출장 실제 세팅·헬기 사진 및 사용 권한. 인터넷 사진으로 실제 상품을 사칭하지 않음.
5. **정확한 장소·동선**: 사용자 확인 범위는 한국해양대 기존 출항지, 군산/변산. 기존 OPS에서 실제 주소·지도·주차 지점 대조 필요.
6. **헬기 운영 상세**: 헤드셋 통신 구조와 교신 우선, 안전한 촬영장비 설치, 지상 이벤트 허용 구역, 10분 관련 시간 정의, 탑승 제한, 촬영 동의, 인물 초상·영상 공유 범위.
7. **영상 납품**: 편집본 길이/해상도/음원/전달 기한/수정 범위, 원본 보존·삭제 정책.
8. **출장 조건**: 지역/출장비, 장소 사용 승인, 설치·철거 소요 및 고객 희망 시간의 의미, 마케팅 동의 거부 시 액션캠 제공 조건.
9. **트렁크 상품**: 확정 상품명·가격·차량 조건·장소/전원 조건.
10. **개인정보와 알림**: 처리 주체/보유기간/동의문, 문자 템플릿/발신번호 인증/잔액/운영 알림 수신자 확정. 법률 준수 완료나 SMS 수신 API 존재를 가정하지 않는다.

이 목록은 미확정 데이터를 임의로 판매 약속으로 바꾸지 않기 위한 출시 점검표다. 전체 고객 UI와 관리자 CRUD 구현은 진행할 수 있다.
