# 요트 날짜별 금액·장소 안내

2026-11-01 사용자가 확정한 기준: 월·화·수·목은 주중, 금·토·일 및 공휴일 전날·당일은 주말 요금. 대체공휴일과 그 전날도 주말 요금이다. 야간 추가금은 만들지 않는다. 정박형 등 주중·주말 가격이 같은 패키지는 동일 가격을 유지한다.

관리자 고객 문자 안내를 열면 행사 날짜에 맞는 금액과 선택 옵션 합계를 채운다. 날짜 변경 시 자동 금액과 네 단계 기본 문구가 함께 갱신된다. 금액을 직접 입력하면 수동 금액으로 유지하고, **날짜 요금 적용**을 누르면 자동 계산으로 돌아온다. 날짜별 지정 가격이 있으면 우선한다. 지정 가격이 미정(null)이면 임의 계산하지 않는다. 상담 접수 당시 상품·옵션 가격을 사용하므로 나중에 게시한 가격이 과거 접수에 소급되지 않는다.

기존 저장 금액과 확정 예약은 보존한다. 금액 변경 시 입금 확인 체크를 해제하며, 확정 예약 변경은 기존 재확정 절차를 거친다. 문자 앱 열기/최종 발송 방식은 그대로다. 자동 금액은 서버에서도 검증한다.

## 공휴일 자료

`pricing.js`에 2026·2027년 확정 공휴일을 넣었다. 날짜는 한국 행사일의 YYYY-MM-DD 값으로 판정하며 브라우저 시간대에 영향을 받지 않는다.

- [한국천문연구원 2026년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2026): 설·추석·석가탄신일·대체공휴일·지방선거일.
- [한국천문연구원 2027년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2027).
- [우주항공청 2027년 월력요항 발표](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431): 2026년 4월 지정된 노동절·제헌절의 2026년 적용과 2027년 대체공휴일을 반영했다. 구버전 2026 달력표에 빠진 항목은 이 발표로 보완했다.

새 연도 월력요항 발표 또는 임시공휴일 지정 시 이 표를 갱신하고 날짜 테스트를 추가해야 한다. 현재 자료 범위 밖 월~목은 주중으로 추정하지 않고 **공휴일 확인 필요**와 수동 금액 입력을 안내한다. 금~일은 연도와 관계없이 주말, 동일 요금 또는 명시적 날짜 가격은 계속 적용 가능하다. 외부 API 호출·유료 서비스는 사용하지 않는다.
