# 상품 보관·복원

관리자 상품 관리에서 `상품 분야`는 목록을 분야별로 걸러 주고, `상품 상태`는 운영 상품 / 보관된 상품 / 전체 상품을 선택한다. 새 상품을 만드는 분야 선택은 별도 `새 상품 추가` 안에 있다.

보관 상품을 되돌리려면 `상품 상태 → 보관된 상품 → 상품 선택 → 복원 → 저장 및 게시`를 누른다. 복원은 기존 상품 ID·사진·패키지·가격·순서를 유지하고, 보관 표시를 해제하며 고객 노출을 켠다. 기존 판매 중지 설정은 유지한다. 초안 저장만 하면 고객 화면에는 아직 적용되지 않는다.

상품을 모두 보관하거나 필터 결과가 없어도 저장 버튼에 접근할 수 있다. 필터 전환 시 편집 중인 내용을 메모리에 보존하며 저장·게시 전에는 서버에 쓰지 않는다. 과거 상담의 상품 스냅샷은 변경하지 않는다.
