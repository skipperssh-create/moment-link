# 휴대폰 회전 설정과 설치 앱 갱신

2026-11-18

모먼트링크는 `manifest.webmanifest`에 `orientation`을 지정하지 않으며 Screen Orientation API로 화면을 강제 회전하거나 잠그지 않습니다. 회전 잠금과 자동 회전은 휴대폰·브라우저가 결정합니다. 세로 고정이나 `any`를 추가하면 이 원칙을 깨므로 사용하지 않습니다.

11월 15일 이전 설치 설정에는 `orientation: any`가 있었습니다. 운영 manifest에서는 이미 제거됐지만 Android의 설치 앱(WebAPK)은 별도 사본을 보관합니다. 일반 새로고침이나 서비스 워커 업데이트만으로 설치 앱 갱신이 완료됐다고 판단하면 안 됩니다. 현재 신고는 예전 설치 설정이 남아 있는 경우와 일치하나, 해당 휴대폰의 설치 메타데이터를 직접 확인한 것은 아닙니다.

이번 보완에서는 manifest를 오프라인 캐시 대상에서 제외하고 HTTP `no-store`를 적용했습니다. 기존 manifest URL·앱 ID·시작 URL은 유지합니다. 공개 화면의 오프라인 사용, 로그인·푸시 구독은 유지하며 고객 데이터·OPS 예약을 수정하지 않습니다. 웹 코드에서 휴대폰의 회전 잠금 상태를 읽거나 설치 앱 갱신을 강제로 완료할 수는 없습니다.

## 이미 설치한 Android 앱

1. 작성 중인 내용을 저장합니다. Wi-Fi에 연결하고 충전기를 꽂은 상태에서 모먼트링크를 한 번 연 뒤 종료합니다.
2. Chrome 주소창에 `about://webapks`를 입력하고 모먼트링크의 `Update`를 누릅니다. 앱을 다시 열었다가 완전히 종료하고 업데이트 상태가 `Successful`인지 확인합니다. 브라우저 버전에 따라 메뉴가 다를 수 있습니다.
3. 업데이트 항목이 없거나 계속 같은 증상이면 모먼트링크 앱을 제거한 뒤 Chrome에서 `https://link.teamboatn.com/`을 열고 다시 설치합니다. 관리자 로그인 및 백그라운드 알림 연결·허용을 다시 확인합니다. 저장된 예약은 서버에 보관됩니다.

임시로 Chrome 일반 탭에서 이용할 수도 있습니다. 재설치한 최신 앱에서도 발생하면 기기 모델, Android/One UI·기본 브라우저 버전과 앱별 회전 설정을 확인합니다.

## 실기기 검수

현재 확인: PWA 자동 검사 5개, 전체 JavaScript 문법 검사, 정적 빌드 47파일 통과. 로컬 브라우저에서 서비스 워커 갱신 알림 → 새 화면 적용을 확인했고, 390×844·844×390·768×1024에서 첫 화면 가로 넘침이 없었습니다. 물리 휴대폰의 회전 잠금 및 설치 앱 업데이트 완료는 확인하지 못했습니다.

- 회전 잠금 켜짐: 접힌 화면·펼친 화면에서 기기를 기울여도 OS 설정과 일치하는지 확인합니다.
- 자동 회전 켜짐: 가로·세로 변경과 기존 폼 입력값 유지 확인.
- 브라우저 viewport 크기 변경은 레이아웃 검수일 뿐, 센서·OS 회전 잠금이나 설치 앱 갱신 검증을 대신하지 않습니다.
