# 예약 확정 및 검색 정리 · 2026-11-01

## 담당자 사용법

1. 상담 접수함에서 고객을 검색하고 상담 상세의 **예약 확정**을 누릅니다.
2. 행사 날짜·협의한 시간·최종 금액·장소를 입력하고, 일정·장소 확정과 입금 확인을 체크합니다.
3. **예약 확정**을 누르면 상태가 확정되고 별도 **확정 예약** 메뉴에서 관리합니다. 이미 종결한 일반 상담도 명시적으로 확정할 수 있습니다.
4. 확정 예약은 행사 일정순으로 표시됩니다. **진행 예정 / 행사 완료 / 취소 / 전체 예약** 필터와 이름·번호·접수번호 검색을 함께 사용할 수 있습니다.
5. 예약 접수·금액 안내 / 결제 후 예약 확정 / 하루 전 안내 / 이벤트 후 안부 버튼으로 해당 문구를 바로 엽니다. 저장 후 고객 번호를 누르면 휴대폰 문자 앱으로 연결하며 최종 전송은 담당자가 합니다. PC에서는 문구 복사를 이용합니다.
6. 확정 정보 변경은 **예약 정보 수정·확정**으로 다시 확인합니다. 행사 종료 후 상세의 상담 상태에서 **행사 완료**를 저장하면 완료 목록에서 안부 문자를 준비할 수 있습니다. 취소 건도 별도 목록에 남습니다.

검색창과 검색 버튼은 한 줄로 묶고, **목록 새로고침**과 검색 중에만 표시되는 **검색 초기화**를 아래에 분리했습니다. Enter 키도 검색합니다. 예약 상세에서는 목록 검색 영역을 숨깁니다.

## 서버와 기존 운영 보호

- `POST /api/admin/consultations/:id/reservation`: 기존 관리자/배정 상담자 권한, CSRF, 행 잠금 및 낙관적 버전 검사. 일정·장소·금액·입금 확인을 검증하고 과거 날짜는 거절합니다.
- 기존 스키마 3의 비공개 `communication.reservation`에 확정 정보 및 담당자를 저장합니다. 별도 마이그레이션이 없고, 기존 상품·가격 스냅샷과 최초 희망 일정은 보존합니다.
- `GET /api/admin/consultations?view=inbox|reservations&status=all|confirmed|closed|cancelled`: 서버에서 권한·보유기한·상태·검색 필터 적용 후 50건씩 조회합니다. 기존 클라이언트의 기본 조회는 `view=all`로 호환합니다.
- 확정 정보의 일반 문자 저장을 통한 변경을 차단합니다. 완료·취소된 예약을 다시 확정하거나 확정 정보를 변경할 수 없습니다. 완료 건은 안부 문자, 취소 건은 문자 준비 차단을 적용합니다.
- OPS 작업 이력이 있는 건의 수동 확정을 차단합니다. 모먼트링크 확정은 외부 OPS 예약 등록이나 입금 자동 조회가 아닙니다. SMS outbox 또는 OPS 작업을 생성하지 않습니다.
- 고객별 문자 초안·발송 확인 기록은 유지합니다. 기존 보유기한도 그대로이며 만료 시 확정 예약을 포함해 조회에서 제외되고 개인정보 정리 정책에 따라 삭제됩니다. 예약 확정이 보유기간을 연장하지 않습니다.
- 서비스 워커 버전 v44로 공개 앱 파일을 갱신합니다. 고객 정보/API 캐시 정책은 변경하지 않습니다.

## 검증과 제한

합성 PostgreSQL 데이터로 권한·CSRF·버전 충돌, 확정·재확정·완료·취소, 서버 필터·검색·일정순·페이지 분리, 확정 정보 보호, 문자 기록 보존, 만료 차단 및 외부 작업 0건을 검증합니다. 실제 고객 예약이나 외부 OPS는 테스트에 사용하지 않습니다.

브라우저에서 합성 상담 확정 → 확정 목록 → 하루 전 문구 준비·복사 → 완료 목록 → 안부 문구 준비, 번호 검색·Enter 검색·초기화·새로고침을 확인했습니다. 320/390/768/844 가로/1440 viewport에서 가로 넘침이 없으며 브라우저 오류 로그가 없습니다. 물리 휴대폰 문자 앱 실행·실발송은 미검증입니다.

현재 코드를 롤백해도 기존 스키마는 유지합니다. 이전 버전은 새 예약 분류 UI가 없으므로 운영자는 확정 상태와 비공개 예약 정보를 함께 확인해야 합니다. 롤백을 위해 DB나 고객 데이터를 삭제하지 않습니다.

## 2026-11-02 관리자 직접 예약 등록

상담 접수 없이 전화·메신저로 받은 예약은 **상담 접수함 / 확정 예약 → + 직접 예약 등록**에서 입력합니다. 관리자 계정만 등록할 수 있습니다.

1. 고객 이름·휴대전화, 상품·패키지·옵션, 이벤트 날짜·시간, 장소·담당자를 입력합니다.
2. 금액은 기존 날짜별 요금과 옵션을 합산합니다. 협의 금액은 직접 입력할 수 있습니다. 요트 장소는 기존 한국해양대학교 안내를 불러옵니다.
3. 입금 전에는 **접수로 등록**합니다. 진행중 상태로 저장되며 기존 상세 화면에서 나중에 확정할 수 있습니다.
4. 일정·장소와 입금을 확인했다면 두 확인 항목을 체크하고 **예약 확정 등록**합니다. 확정 예약 목록에서 일정순으로 관리하며 네 단계의 고객 문자를 준비할 수 있습니다.

목록에 **관리자 직접 등록**을 표시합니다. 등록 직후 상세 화면과 해당 단계의 문자 안내가 열리며, 문자 발송은 기존 문자 앱 연결 방식으로 담당자가 진행합니다. 실제 가능한 일정은 운영자가 확인해야 하며 외부 OPS나 재고를 자동 예약하지 않습니다.

- `POST /api/admin/reservations`: 관리자 인가·CSRF, 상품 게시 버전·판매 가능 상태·옵션 의존성·담당자·금액·미래 일정 검증. 동일 요청 재전송은 같은 건을 반환하고 변경된 중복 요청은 거절합니다.
- 기존 상담 저장 구조와 예약 확정 로직을 재사용합니다. 상품·가격 스냅샷, 직접 등록 출처와 담당자 감사 이력을 기록하며 고객의 웹 동의 여부를 허위로 생성하지 않습니다.
- 기존 개인정보 보유기간을 적용하고 등록·확정으로 연장하지 않습니다. 입력 중 개인정보는 메모리에만 유지합니다. 직접 등록은 새 고객 문의 알림 집계에서 제외합니다.
- DB 마이그레이션, 문자 outbox, OPS 쓰기, 유료 서비스 설정 변경이 없습니다.

## 2026-11-02 새 상담 음성 안내

관리자 화면 상단의 **음성 알림 켜기**를 누르면 예시 음성이 재생되고, 이후 화면을 보고 있는 동안 새 상담을 감지할 때 **모먼트링크, 새로운 상담이 접수되었습니다**로 알려줍니다. **미리 듣기**는 소리만 시험하며 알림 설정을 켜지 않습니다. 기존 30초 자동 확인과 수동 새로고침에서 작동하고 같은 상담은 반복해 읽지 않습니다.

새로 연 화면에서는 다시 켜 주세요. **음성 알림 끄기**로 중단할 수 있으며 기기 미디어 볼륨과 한국어 음성 설정에 따라 음량·음색이 달라집니다. 화면이 숨겨지면 음성이 멈추고, 앱을 닫거나 화면을 끈 상태의 푸시는 휴대폰 기본 알림음 설정을 따릅니다. 음성에는 고객 이름·전화번호를 포함하지 않습니다.

상담 목록의 **문자 안내** 버튼은 제목 아래에 고객 번호를 한 줄로 표시합니다. 해당 버튼은 문자 작성 화면을 열며 실제 전송은 기존 방식대로 담당자가 진행합니다.
