# 설렘 OPS 자동 예약 등록

배포 이후 처음 확정한 출장·트렁크 예약만 전용 outbox에 등록한다. 기존 예약을 재확정하거나 상담중으로 되돌렸다가 확정해도 소급 등록하지 않는다. 기존 BOATN 작업이 있으면 등록하지 않으며 그 작업과 충돌은 변경하지 않는다.

확정 일정·장소·총액·실제 입금액·상품 선택·취소를 같은 원본 참조로 전달한다. 새로운 변경은 revision을 올리고, 전송 중 변경도 다음 전달에 남는다. 매 revision의 전송 본문을 보관하여 불명확한 재시도도 같은 내용으로 보낸다. 최대 2회 실패하면 멈추며 충돌은 자동 재개하지 않는다. 상담 상세에 설렘 OPS와 구글 캘린더 상태·오류 코드를 별도로 표시한다.

구글 캘린더는 기존 event_calendar_jobs 경로만 사용한다. 설렘 OPS가 같은 예약을 다시 Google에 쓰지 않으므로 일정이 복제되지 않는다. 신규 예약의 Google 이벤트 ID는 기존 규칙을 유지한다.

환경: `SEOLLEM_BOOKING_SYNC_ENABLED=true`, `SEOLLEM_BOOKING_SYNC_URL`은 설렘 OPS `/api/integrations/moment-link/bookings`, `SEOLLEM_BOOKING_SYNC_TOKEN`은 새 전용 서버 토큰. OPS 수신 서버를 먼저 배포·연결 검사한 뒤 발신을 배포한다. 기존 OAuth·BOATN 환경값은 변경하지 않는다.

신규 확정 및 변경 요청 후 즉시 처리하고, 기존 2분 알림 작업에서도 미처리 outbox를 처리한다. 수신 실패가 고객의 확정 저장을 되돌리지는 않는다. 임의 backfill·운영 시험 예약·충돌 해소·문자 발송은 포함하지 않는다.
