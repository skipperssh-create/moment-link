# 짧은 문자와 예약 상세 안내

2026-11-14 사용자 요청: 긴 문자에서 내용이 잘리므로 시간·금액 등 주요 정보는 문자에 남기고 환불규정과 준비사항은 링크로 안내한다.

## 문자에 유지하는 정보

- 고객 이름과 전화번호, 이벤트 날짜·시간, 확정 장소 전체 주소
- 상품·패키지·선택 옵션·추가 구매, 총액·입금 확인액·남은 금액
- 접수 안내의 계좌, 명시적으로 선택한 예약금 안내 또는 전액 입금 안내, 적용되는 입금 기한
- 영상편지 포함 예약의 제출 기한 또는 7일 이내 일정의 사전 협의 안내
- 확정된 요트 예약의 기존 OPS 승선신고·보딩패스 링크
- 직원이 직접 작성한 추가 안내와 문의 연락처

## 공개 안내 페이지

`https://link.teamboatn.com/guide.html?v=1&t=yacht&video=1`

`t`는 yacht/visit/trunk/heli/all만 사용한다. `video=1`은 영상편지 포함, 트렁크 `mode=visit`은 출장 수거 안내다. URL에는 고객 식별자·이름·연락처·날짜·금액·보딩패스 토큰을 넣지 않는다. 공개 정적 페이지이며 API·인증·고객 데이터 저장 없이 열린다. 이름/날짜/금액이 필요한 안내는 받은 문자를 확인하도록 한다.

기존 요트·출장 환불표와 요트 날짜 변경 1회, 상품별 준비·날씨·수거 안내, 고객이 지정한 영상자료 템플릿과 `seolvidmoa@gmail.com`을 그대로 보존한다. 트렁크·헬기에 미확정 환불표를 추가하지 않는다. 제출 기한이 있는 개별 날짜는 문자에만 표시한다.

**버전 1의 계약·준비 조건은 이 파일과 guide.html에서 고정한다.** 향후 조건 변경 시 별도 버전 페이지를 만들어 새로 생성하는 링크만 변경하고, 이미 발송한 v1 링크의 내용은 소급 변경하지 않는다. 알 수 없는 버전은 임의로 현재 규정을 표시하지 않고 담당자에게 링크 확인을 요청한다.

## 기존 초안

상세 화면에서 불러올 때 알려진 자동 생성 문단만 링크 안내로 바꾼다. 기존 안내와 다른 특약·직원 메모·직접 쓴 문구는 유지한다. 원본 DB를 일괄 수정하거나 예약·금액·OPS 작업을 재처리하지 않는다. 직원이 문자 준비를 눌러야 변경한 초안이 저장되며, 보딩패스는 기존 검증 및 본문 해시를 새로 확인한다. 자동 발송은 없다.

문자 안내에 상세 안내 미리보기를 제공한다. 700자가 넘는 개별 안내에는 길이 경고를 표시한다. 이 기준은 통신사 최대 길이 보장이 아니며, 실제 문자 앱에서 끝부분을 확인해야 한다.

## 검증

`tests/guide.test.mjs`는 공통 조건 보존, 개인정보 없는 링크, 짧은 문자, 예약금 선택, 기존 초안과 보딩패스 보존, 상품별 표시 및 잘못된 버전을 검사한다. `tests/messages.test.mjs`와 기존 보딩패스·결제·OPS 충돌 검사도 함께 실행한다. 합성 DB만 사용하며 실제 예약·OPS 충돌·문자 발송을 변경하지 않는다.

2026-11-14 브라우저 도구가 “Local browser use is disabled in Work settings”를 반환했다. 실제 폰 접힘·펼침 화면과 문자 앱 전달은 미검증이다. 반응형 CSS는 320px부터 사용할 수 있도록 가변 폭, 줄바꿈, 좁은 화면의 1열 항목, 문서 흐름 안의 버튼을 적용했다.

문법 검사와 전체 자동 검사 194개가 통과했다. 합성 요트 올인원·부분 입금 예시에서 확정 문자는 보딩패스 추가 전 356자, 예약금 안내는 583자다. 개별 메모·옵션·보딩패스에 따라 실제 길이는 달라진다. 실제 예약 및 OPS 데이터 변경은 하지 않았다.
