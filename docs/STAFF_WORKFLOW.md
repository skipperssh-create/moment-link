# 담당 상담사 운영

- 직원 계정에서 이름·아이디·임시 비밀번호를 등록합니다. 상담자는 첫 로그인에 비밀번호를 변경해야 합니다.
- 상담자는 내 상담, 관리자는 전체 상담으로 시작합니다. 전체·미배정·직원별 필터는 함께 조회할 수 있습니다.
- 미배정 카드의 상담 시작은 현재 직원에게 원자적으로 배정합니다. 접수중은 상담중으로 바뀌며, 동시 요청 중 한 명만 맡습니다.
- 상담자는 본인 담당 상담의 상태·메모·예약·문자 기록을 수정합니다. 다른 직원 담당은 조회 전용입니다. 관리자만 인계 사유를 남겨 담당자를 변경합니다.
- 기존 미배정 상담을 관리자가 실제로 처리하면 관리자에게 배정됩니다. 단순 열람으로는 배정하지 않습니다. 기존 담당자를 임의로 바꾸거나 기존 데이터를 일괄 배정하지 않습니다.
- 예약 확정·수정·취소·복원에도 담당자를 유지합니다. 기존 OPS 충돌 재시도 정책은 그대로입니다.
- 리마인드 할 일은 한국 날짜로 내일 이전 행사 중 전날 안내 발송 기록이 없는 확정 예약을 표시합니다. 지난 행사도 기록 확인이 필요하면 남으며, 취소·완료 건은 제외됩니다.
- 문자 준비나 문자 앱 열기는 발송 완료가 아닙니다. 실제 발송 후 휴대폰 발송 완료 기록을 눌러야 할 일에서 빠집니다. 발송 확인자와 현재 예약 날짜·시간이 저장됩니다. 수신 확인이나 자동 SMS 발송을 의미하지 않습니다.
- 일정 수정·복원 이후에는 이전 발송 기록으로 새 안내를 완료 처리하지 않습니다.

## 구현과 검증

기존 assignee 및 config의 비공개 staff:<uuid> 이름 정보를 사용하며 별도 테이블 변경은 없습니다. API는 로그인·첫 비밀번호 변경·CSRF 검증 후 공유 조회와 담당자 쓰기 권한을 구분합니다. 인계와 동시 배정은 상담 행 잠금 안에서 처리합니다.

114개 테스트 통과: 담당자 필터, 동시 배정, 조회/쓰기 권한, 관리자 인계, 계정 생성, 리마인드 기록 및 기존 예약·OPS 회귀 검사. 합성 데이터로 직원 로그인→상담 시작→내/전체/직원별 조회→리마인드 기록→할 일 제거와 관리자 인계 화면을 검수했습니다. 9개 브라우저 크기에서 가로 넘침을 확인했습니다. 실제 휴대폰 기기·문자 실발송 테스트는 포함하지 않습니다.
# 2026-11-07 상태 색상·변경 이력·입금 유효시간

카드와 상태 필터는 같은 파스텔 색상을 사용합니다. 접수중은 연회색, 최초연락안됨·답변없음은 분홍, 상담중은 연보라, 입금대기는 파랑, 확정은 초록, 보류는 연노랑, 완료·취소는 회색입니다. 선택된 필터는 테두리로 구분합니다.

접수·상담 시작·상태 변경 시각을 한국 시간의 날짜와 분 단위로 표시합니다. 카드의 상태 변경 이력과 상세 변경 이력에서 전후 상태와 담당자를 확인할 수 있습니다. 과거 감사 기록으로 확인되지 않는 상태 시각은 임의로 만들지 않습니다.

입금대기 유효시간은 **입금대기로 변경한 시각부터 2시간**입니다. 메모·연락 여부 저장이나 동일 상태 재저장, 문자 재준비로 연장되지 않습니다. 다른 상태로 변경했다가 입금대기로 다시 전환하면 새 전환 시각부터 계산합니다. 기한 전에는 남은 시간을 표시하고, 기한 후에는 카드에 주황빛 경고를 표시합니다. 화면이 열려 있으면 기존 30초 갱신 주기에 맞춰 경고를 갱신하며 메모 입력을 보존합니다.

경고 → 문자 안내의 **입금 리마인드** → 문자 준비 → 문자 열기 순서로 안내합니다. 문자 앱의 실제 전송은 담당자가 진행합니다. 입금 확인 기한이 지났다는 이유만으로 예약을 취소하거나 OPS 작업을 재시도하지 않습니다. 발송 완료 기록은 해당 입금대기 회차에만 표시하고, 문자 앱 열기 요청과 실제 발송 기록을 구분합니다.
