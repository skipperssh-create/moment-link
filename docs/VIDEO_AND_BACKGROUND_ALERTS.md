# 영상편지 자료 안내와 기기별 백그라운드 알림

2026-11-12 사용자 요청 반영.

- 영상편지가 포함되거나 선택된 요트·출장 상품의 접수/확정 문자: 자료는 이벤트 7일 전까지 전달하고, 수정은 오타에 한해서 가능하다고 안내한다. 한국 날짜 기준 7일 이내 예약은 과거 제출 기한 대신 담당자와 자료 전달 일정·제작 가능 여부를 먼저 협의하도록 표시한다.
- 기존 저장 문구는 알려진 영상편지 안내 부분만 새로 준비할 때 정리한다. 개별 메모, 금액, 고객 정보, 보딩패스 링크 및 이미 발송한 이력은 일괄 수정하지 않는다.
- 관리자 접수함에 이 기기의 백그라운드 푸시 연결 상태, 알림 연결, 알림 확인을 표시한다. 권한 요청과 재연결은 담당자가 눌렀을 때만 실행한다. 알림 확인은 로그인한 본인의 현재 기기 한 곳으로만 테스트한다. 새 상담·예약·OPS 작업을 만들지 않는다.
- 해제도 현재 기기만 대상으로 한다. 연결 상태 조회는 읽기 전용이며 고객 내용·다른 기기의 endpoint·비밀키를 반환하지 않는다.
- 새 상담 푸시는 높은 우선순위와 1시간 TTL을 요청한다. 휴대폰 알림 권한, 소리·진동, 방해 금지 및 절전 정책은 기기 설정을 따르며 웹앱에서 강제로 바꾸지 않는다. 화면 안의 브랜드 음성과 OS 푸시 알림은 별개다.
- 테스트 알림은 자동 재시도하지 않고 1분에 2회로 제한한다. 결과는 발송 서비스 접수와 실제 기기 수신을 구분한다. 만료된 구독은 해당 기기만 해제하고 재연결을 안내한다.

검증: 문법 검사, 합성 PGlite/VM 기반 전체 190개 검사 통과. 기기 소유자·권한·CSRF·2회 제한·구독 만료·현재 기기 해제·신규 접수 TTL·서비스워커 알림·한국 날짜 7일 경계·기존 안내 보존을 확인했다. 실제 예약 및 OPS 충돌 건 변경, 고객 문자·푸시 발송 0건.

운영 원인 조사: 최근 7일 푸시 19건은 서버 outbox에서 발송 서비스 접수 상태이고 활성 관리자 구독은 2개였다. 이 기록만으로 해당 휴대폰에서 알림이 실제 표시·재생됐다고 판단할 수 없다. Work에서 로컬 브라우저 사용이 꺼져 있어 브라우저 화면 및 실기기 백그라운드 수신 검수는 미실시다.
