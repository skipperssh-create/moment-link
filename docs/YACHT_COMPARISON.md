# 요트 상품 구성 비교 · 2026-11-01

사용자가 마지막으로 첨부한 표에 맞춰 각 요트 카드의 라이트·올인원 포함 항목을 ✓ / –로 표시한다. 앞서 만든 요트 3종 가격 종합표는 제거했다. 가격·이용시간은 기존 패키지 선택 카드에 유지한다.

## 첨부표 기준 출항형 구성

| 포함 내용 | 라이트 | 올인원 |
|---|---|---|
| 단독 요트 대관 | 포함 | 포함 |
| 요트 투어·프로포즈 | 포함 | 포함 |

CLASSIC·PREMIUM·SIGNATURE 출항형에 적용한다. 정박형은 기존에 확인된 구성으로 같은 표 형식을 사용하며 출항형의 투어·추가 품목을 복사하지 않는다. 꽃다발은 기존 올인원 카드 안내에 유지한다.

이후 사용자가 추가한 영상촬영 (마케팅 동의 시)은 출항형·정박형 모두 라이트·올인원에 포함으로 표시한다. 촬영·마케팅 활용 동의가 조건임을 항목 이름에 명시한다.

포함 항목은 카탈로그 features, 명시적 미포함 항목은 excludedFeatures로 관리한다. 관리자에서 두 목록을 편집할 수 있고 같은 항목을 양쪽에 동시에 넣으면 서버에서 거절한다. 두 목록 모두에 없는 내용은 미포함으로 추정하지 않고 '상담 확인'으로 표시한다. JSON 카탈로그의 선택 필드 추가로 기존 데이터·상담 스냅샷과 호환되며 DB 스키마 변경은 없다.

첨부표와 같은 간결한 행 구분선, 제목, 체크·대시를 사용한다. 기호에 포함/미포함 접근성 이름을 붙이고 열/행 제목을 제공한다. 현재 두 패키지 구성은 320px에서도 표 안의 가로 스크롤 없이 보인다.

## 검증

- 서버 회귀 테스트 32개 통과: 미포함 항목 저장/공개, 포함·미포함 충돌 거절, 이전 카탈로그 호환 포함.
- 출항형·정박형 × 320×740, 390×844, 844×390, 768×1024, 1440×1000의 10개 브라우저 크기에서 표/페이지 가로 넘침 및 셀 잘림 없음.
- 출항형 세 상품의 9개 행과 체크/대시를 첨부 이미지와 대조했다. 정박형 미확정 항목은 상담 확인으로 유지한다.
- 증거: test-artifacts/yacht-inclusion-responsive.json. 실제 물리 기기 검수는 아니다.

상품 가격, 사진, 일정 및 상담 흐름, 운영 설정은 유지한다. 문자 발송·유료 서비스·기존 OPS 변경 없음.
