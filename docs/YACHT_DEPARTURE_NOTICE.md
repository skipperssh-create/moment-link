# 요트 출항지 안내 (2026-11-21)

고객이 서비스 선택에서 요트 프로포즈를 누르면 출항지 안내 dialog를 먼저 보여준다. 닫기·확인·Escape로 닫은 뒤 기존 상품 비교를 그대로 이용하며 상품 화면에서 다시 열 수 있다. 출항형·정박형을 바꿀 때나 일정 화면에서 돌아올 때 반복 팝업을 강제하지 않는다. 출장·트렁크·헬기·관리자 화면에는 자동 표시하지 않는다.

## 고객 문구 기준
- 핵심: 평생 기억할 프로포즈, 멀미 걱정보다 설렘에 집중하세요.
- 수영만의 재개발·운영 중단과 모먼트링크의 부산항(영도) 출항을 구분한다.
- 부산항대교·시티뷰는 운영자가 제공한 코스 정보이다. 대형 크루즈는 정박 및 코스 조건부로 안내한다.
- 조도·오륙도 방파제의 항내 정온 효과를 설명하되 부산에서 가장 잔잔하다는 비교 우위, 무조건 운항 가능, 멀미 없음은 보장하지 않는다.
- 3~4년 이상 운항 불가는 검증되지 않아 넣지 않는다. 부산시 자료의 준공 목표도 갱신 이력이 있어 재개장 시점은 공식 안내에 따른다고 적는다.
- 정박형은 출항하지 않는다는 조건을 구분한다. 기존 승선 주소·가격·예약·OPS·문자는 변경하지 않는다.
- 첨부된 기존 출항지 철거 사진을 새로운 부산항 코스의 사진으로 사용하지 않는다.

## 검수
클라우드 Chromium에서 320×740, 360×800, 390×844, 844×390, 884×1104, 1104×884, 768×1024, 1024×768, 1366×768, 1440×900을 검사했다. 닫기·확인 버튼이 화면 안에 유지되고 본문·출처를 스크롤로 볼 수 있다. Escape 및 포커스 복귀, 기존 패키지 선택 보존, 정박형·일정 왕복, 다른 서비스에서 미노출을 확인했다. 오류·변경 HTTP 요청은 0건. 물리 휴대폰 검수와 구분한다.
