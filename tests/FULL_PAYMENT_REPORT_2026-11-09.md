# 고객 연락처·완납 입력 검수 — 2026-11-09

- 예약 접수·확정·이벤트 전 안내의 상품 요약에 고객 연락처를 표시합니다. 기존 저장 문구의 상품 요약에도 추가하며 별도 작성 내용은 유지합니다.
- 상담 상세와 직접 예약 등록의 실제 입금액 옆에 완납 버튼을 추가합니다. 추가 구매를 포함한 총액을 입력하고 입금 확인을 체크합니다. 일정 확인은 변경하지 않습니다.
- 완납 버튼은 입력만 변경합니다. 예약사항 저장 또는 예약 확정을 눌러 서버에 저장합니다. 미정·잘못된 총액은 자동 입력하지 않습니다.
- OPS에 연결된 예약의 입금 필드 잠금은 유지하며 기존 입금 확인 흐름을 사용합니다. 기존 충돌 건을 재시도하거나 운영 예약을 변경하지 않았습니다.

검증: messages, booking-addons, deposits, direct-booking, collections, pwa의 관련 테스트 36개 통과(초기 34개 실행 후 새 저장·직접 등록 테스트를 추가하여 변경한 두 테스트 파일 26개 재실행). 완납 입력 → 저장 요청 → DB 저장 → 재조회 → 확정, 잔금 0원, 문자 본문 연락처, 기존 OPS 충돌 보호를 확인했습니다. 문법 검사와 정적 빌드 통과.

한계: 브라우저 연결이 두 번 시간초과되어 이번 변경의 화면·실기기 검수는 완료하지 못했습니다. 실제 고객 문자 전송은 하지 않았습니다.
