# 화면 경계 검수 — 2026-11-09

## 수정
- 상담 목록·상세의 상태 선택과 담당자 선택 메뉴를 공통 배치 함수로 처리합니다.
- 지원 브라우저에서는 top layer를 사용하여 카드의 위치·컨테이너에 영향을 받지 않게 합니다.
- 화면 경계 12px, 위아래 가용 공간, 스크롤바, visual viewport를 고려합니다. 화면 크기가 바뀌어도 CSS 경계 제한이 유지됩니다.
- 이전 브라우저에는 좌표 보정 fallback을 유지합니다. 스크롤·화면 크기·본문 재배치 시 위치를 갱신합니다.
- 상태 저장, 고객 데이터, OPS 연동 로직은 변경하지 않았습니다.

## 브라우저 확인
격리된 로컬 PGlite 합성 데이터와 Chrome을 사용했습니다. 실제 운영 데이터·문자·OPS 예약은 변경하지 않았습니다.

뷰포트: 320×740, 360×800, 390×844, 600×900, 690×820, 768×1024, 844×390, 1024×768, 1440×1000. 세로 스크롤바가 있는 경우 콘텐츠 너비는 약 15px 작습니다.

각 9개 크기에서 페이지 가로 넘침과 보이는 요소의 좌우 경계를 검사한 화면:
- 상담 목록, 상담 상세, 상담 상세의 담당 관리 펼침
- 확정 예약 목록, 확정 예약 상세, 직접 예약 등록
- 상품 관리, 기본 상품의 사진·패키지·추가 옵션 펼침
- 문자·알림, 모든 안내 문구 펼침
- 장소 관리, 신규 장소 편집 펼침
- 접수·개인정보, OPS 연동, 직원 계정

수정한 상세 상태 메뉴·담당자 메뉴는 열린 상태로 9개 크기를 전환하여 좌우·상하 경계 넘침이 없음을 최종 확인했습니다. Escape로 메뉴 닫기도 확인했습니다.

추가 상품별 편집·고객 신청 화면 검수는 브라우저 연결 시간 초과가 두 번 발생해 완료하지 못했습니다. 실제 폴드·휴대폰 실기기 검수는 아니며 브라우저 크기 시뮬레이션 결과입니다.
