## 중요한 검증 한계
- Chromium 헤드리스 브라우저에서 실제 소스 CSS/JS를 렌더링했다. 실행 환경의 웹 주소 탐색 제한으로 로컬 HTTP 서버에 접속하지 않고 inline DOM에 같은 소스를 넣어 실행했다.
- localStorage는 테스트용 메모리 어댑터로 대체했다. **실제 브라우저 저장소의 재시작/새로고침 지속성·용량 제한을 검증한 결과가 아니다.**
- 실제 폴드/아이폰/아이패드/태블릿 하드웨어 테스트가 아니다. 기기별 정확한 해상도를 주장하지 않으며 넓이/높이의 대표 구간 검사다.
- Safari/WebKit/Firefox, 실제 키보드/안전영역/접근성 스크린리더/200% 확대는 아직 별도 검증 대상이다.
- SMS 앱 실행/발송, 클립보드 OS 권한, PWA 설치, 서비스워커 네트워크/업데이트, 실제 푸시, SOLAPI, 로그인/DB/OPS 연동은 테스트하지 않았다.
- 사진은 실제 운영 사진이 아닌 등록 자리표시자다. 실제 이미지 업로드·네트워크 실패·큰 이미지 최적화도 운영판에서 검수해야 한다.

## 재실행
```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m http.server 4173 --bind 127.0.0.1
# 별도 터미널
python tests/test_preview.py --url http://127.0.0.1:4173
```

현재 환경에서 사용한 명령:
```bash
python tests/test_preview.py --isolated --chromium /usr/bin/chromium --phase flows
python tests/test_preview.py --isolated --chromium /usr/bin/chromium --phase responsive
```

상세 assertion 목록: `results-flows.json`, `results-responsive.json`. 시각 캡처: `../previews/`. 검증 결과는 운영 출시 승인이나 안전·법률 준수 인증이 아니다.
